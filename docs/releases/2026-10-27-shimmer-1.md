# Shimmer 3.26.10272145（2026-10-27）

首个独立发布。使用独立安装身份，可与 Legado、阅读 Archive 同时安装。

## 独立化

- 包名与档案完全独立，旧版数据需通过「备份与恢复」迁移。
- 更新检查只读本仓库的 GitHub Release。
- 签名密钥移出仓库，改由 CI Secrets 注入。
- 版本号改为时间戳，与构建产物直接对应。

## 自有改动

- **听书跟随翻页**：手动翻页时听书自动跳到当前页，跨章节同样生效。
- **书源查重按分组**：查重时可以只处理指定分组。
- **备份区分本地与云端**：云端备份失败不再中断本地备份。
- **水墨风格图标**。

## 安装

| 项 | 值 |
| --- | --- |
| 版本 | 3.26.10272145 |

## 已知限制

- 自动化回归、浏览器渲染比较、安装包校验均已通过；实际设备的显示效果、触控手感和整机帧率尚未测量。
- 仅提供上述两个 ABI。
